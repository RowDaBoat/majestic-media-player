Licenses of the libraries inside libmpv-2.dll
=============================================

libmpv-2.dll is shinchiro/mpv-winbuild-cmake's build of 2026-10-05 (release
20261005, recipe commit 05a60b3cfd04e3e3b89918f4a27f3dde2935dff2). Built for
x86-64, it links the 89 packages its recipe's mpv target depends on, listed
here with the license files each one had when that build ran: the newest
commit before 2026-10-05 00:00 UTC on the branch the recipe follows, or the
release it names. Each folder holds that package's files, unchanged.

Notes:
- x265's 8-bit and 10-bit builds (x265-8+10bit, x265-10bit-lib) are both x265.
- opus-dnn is Opus's model data (opus_data-8a07d57c...tar.gz), under Opus's license.
- avisynth-headers and nvcodec-headers are headers only, with their license in
  them: the license blocks of the headers FFmpeg uses are copied here.
- libopenmpt here is the copy built into libmpv (0.7.12); the tracker chart's
  libopenmpt.dll (0.8.9) has its own folder, ../libopenmpt.
